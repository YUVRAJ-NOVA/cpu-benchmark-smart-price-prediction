## Description

CPU Insight Engine is an advanced, data-driven platform for analyzing CPU benchmarks, comparing processors, and predicting performance using machine learning models. This project demonstrates full-stack development skills combining modern web technologies with data science and machine learning.

## Technology Stack

### Frontend
- **React 18** - UI library
- **TypeScript** - Type safety
- **Vite** - Build tool
- **Tailwind CSS** - Styling
- **shadcn/ui** - Component library
- **Recharts** - Data visualization
- **TanStack Query** - Data fetching
- **React Router v6** - Routing

### Backend
- **FastAPI** - Python web framework
- **Pandas** - Data manipulation
- **NumPy** - Numerical computing
- **scikit-learn** - Machine learning
- **Pydantic** - Data validation
- **Uvicorn** - ASGI server

## Data Source

CPU benchmark data is based on PassMark CPU Benchmark dataset (modified for this project).
